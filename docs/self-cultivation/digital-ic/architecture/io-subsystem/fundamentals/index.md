# Some Fundametals of I/O Subystem

## I. Concepts

#### 1. 引脚（Pin）：物理触点

**引脚是芯片封装上肉眼可见的金属触点**，是芯片与外部世界电气连接的物理端点。

在高速差分信号中，一个方向需要**一对引脚**（P 正极和 N 负极）来传输。所以在引脚图上看到的往往是成对出现的。

#### 2. 通道（Lane）：一对差分信号线

**“通道”在高速串行接口语境下，通常指一个双向的差分信号链路**，即：

- **发送方向**：一对引脚（TX_P / TX_N）
- **接收方向**：一对引脚（RX_P / RX_N）

所以一个完整的通道 = **4 个引脚**（2 个发送 + 2 个接收）。

PCIe/CXL 中说的 **x8**，就是 **8 个这样的通道**并行工作，共 32 个引脚（8×4），提供 8 倍带宽。

> 注意：“通道”一词在不同语境下含义不同。CXL 协议里还有“虚拟通道（Virtual Channel）”的概念，那是逻辑层面的流量分类，不是物理通道

#### 3. SerDes 通道：带收发电路的通道

**SerDes 是 Serializer/Deserializer（串行器/解串器）的缩写**。SerDes 通道指的是**一个完整的串行收发链路**，它不仅包含引脚，还包含背后的模拟电路（发送器、接收器、时钟恢复等）。

#### 4. 端口（Port）：逻辑接口实例

**端口是协议层面的逻辑概念**，指一个完整的接口实例。比如：

- 一个 **x8 的 CXL 端口** = 8 个通道组合在一起，对外表现为一个 CXL 接口
- 一个 **x16 的 PCIe 端口** = 16 个通道组合

端口不直接对应某个引脚，而是**一组通道的集合**。

#### 5. 收发器（Transceiver）：硬件电路，不是引脚

**收发器是一块硬件电路（模拟混合信号电路），不是引脚本身。** 它负责：

- **发送方向**：把芯片内部的并行数字信号 → 串行化成高速差分信号 → 驱动到引脚上
- **接收方向**：从引脚接收高速差分信号 → 恢复时钟 → 解串成并行数字信号 → 送给内部逻辑

所以收发器是**引脚背后的“翻译器+驱动器”**。引脚是触点，收发器是让触点能跑高速信号的那套电路。

> 在 Versal Premium Gen 2 中，**GTM2 就是一种收发器**，它支持 NRZ/PAM4 调制，单通道速率可达 112 Gb/s。CPM6 通过专用连接连接到一组 16 个 GTM2 收发器通道——也就是说，**CPM6 背后有 16 个 SerDes 通道的硬件资源**，可以配置成 2 个 x8 的 CXL 端口。
